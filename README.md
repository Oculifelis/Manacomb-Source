# Manacomb

Source code of [Manacomb](https://www.curseforge.com/projects/1793766), a small Minecraft mod that runs the Complicated
Bees machines on Botania mana: aim a Mana Spreader at a machine, or give it a Mana Spark. Its sister mod is
[Apiflux](https://www.curseforge.com/projects/1793756), which does the same with Create rotation.

Build with `./gradlew build`.

By Oculifelis. Downloads and the changelog are on CurseForge.
